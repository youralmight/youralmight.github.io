Data and questions

This post uses the player and tournament-result tables for Red Bull Wololo: Legacy 2022 – Age of Empires IV. It asks which countries were represented, what placements their players achieved, and how much prize money they received.

The source’s Website Terms of Use grant permission to use the site’s materials for personal and commercial use. This post uses only attributed tabular facts and does not reproduce site images, logos, or trademarks.

The CSV files are stored in the repository’s data/ directory. The two tables are kept separate until the merge step so that the data relationship remains explicit.

import matplotlib.pyplot as plt
import pandas as pd

player_profiles = pd.read_csv("../../data/player_profiles.csv")
tournament_results = pd.read_csv("../../data/tournament_results.csv")

Joining and summarising the tables

joined_results = tournament_results.merge(player_profiles, on="player_id", validate="one_to_one")
country_summary = (
    joined_results.groupby("country", as_index=False)
    .agg(players=("player_id", "count"), total_prize_usd=("prize_usd", "sum"))
    .sort_values(["players", "total_prize_usd"], ascending=False)
)
placement_by_country = pd.crosstab(
    joined_results["country"],
    joined_results["placement"],
)

print(country_summary.to_string(index=False))
