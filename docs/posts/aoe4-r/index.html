Data and questions

This post uses the player and tournament-result tables for Red Bull Wololo: Legacy 2022 – Age of Empires IV. It asks which countries were represented, what placements their players achieved, and how much prize money they received.

The CSV files are stored in the repository’s data/ directory. The two tables are kept separate until the join step so that the data relationship remains explicit.

player_profiles <- read.csv("../../data/player_profiles.csv", stringsAsFactors = FALSE)
tournament_results <- read.csv("../../data/tournament_results.csv", stringsAsFactors = FALSE)

Joining and summarising the tables

joined_results <- merge(tournament_results, player_profiles, by = "player_id")
country_summary <- aggregate(
  prize_usd ~ country,
  data = joined_results,
  FUN = sum
)
country_summary$players <- as.integer(
  table(joined_results$country)[country_summary$country]
)
country_summary <- country_summary[, c("country", "players", "prize_usd")]
